# 中国象棋 · Xiangqi

这是一个静态网页版中国象棋小游戏，使用腾讯 WorkBuddy 生成（使用即将过期的奖励积分），无需安装，打开即玩。棋盘、棋子与规则逻辑全部包含在单个 `index.html` 文件中，没有任何外部依赖。

## 功能

- 完整象棋规则：蹩马腿、塞象眼、炮隔子吃子、飞将（将帅照面）等
- 点击棋子走子，合法落点高亮显示
- 将军、将死与困毙判定
- 悔棋与重新开始
- 中文记谱走子记录
- 吃子展示
- 双人对弈与人机对战模式
- 移动端自适应

## 游玩方法

- 在线游玩：https://wzz2333.github.io/xiangqi-game/
- 本地游玩：下载本仓库后，用浏览器直接打开 `index.html` 即可。
